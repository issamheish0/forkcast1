# Floor Plan (Add‑on)

## 1. What the floor plan add‑on is for

The floor plan add‑on gives your team a **visual layout of tables** linked to bookings.

If your restaurant does not have this add‑on enabled, you will not see the floor plan.

## 2. Key actions on the floor plan

1. **Tap a table** to see:
   * Current guest
   * Party size
   * How long they have been at the table
   * Upcoming reservations for that table
2. **Use quick actions** (when available) to:
   * Seat guests
   * Move guests to a different table
   * Update table / booking status as service progresses
3. **Layout mode** (when enabled)
   * Long‑press / drag to move tables on the screen.

Plate checks capacity and warns you if:

* A table is already occupied
* A future reservation is about to use that table
* The selected tables are too small for the party size
