# Card guarantee

Card guarantees are configured in the **Card Guarantees / Guarantees** section and are also a core feature.

You can:

* Set up guarantee rules for no‑show and late‑cancellation fees.
* Choose the fee type:
  * **Per cover** – fee per guest, multiplied by party size.
  * **Fixed** – one amount for the entire booking.
* Define when guarantees are required (for example, busy time slots or large parties).

**To configure card guarantees**

1. Open **Settings → Guarantees / Card Guarantees**.
2. For each rule, set:
   * No‑show fee amount
   * Late‑cancellation fee amount
   * Fee type (per cover or fixed)
3. Choose when these rules apply.
4. Save to activate.

Once configured:

* Bookings that require a guarantee will prompt staff (or guests via the widget) to provide card details.
* Guarantees can later be charged, released, or waived according to your policy.
