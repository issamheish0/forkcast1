# Basic Dashboard

## 1. What the basic dashboard is for

The basic dashboard is your team’s **daily view of bookings**.

It helps you:

* See **today’s bookings** (and other dates you select)
* Accept & Decline bookings
* Quickly **search bookings**
* Create a **new booking** when needed

## 2. Main parts of the basic dashboard

*   **Top status bar**

    * Shows the totals for the selected date (by default, today), such as:
      * Pending
      * Accepted (number of bookings)
      * Guests (number of guests)

    <figure><img src="../.gitbook/assets/Screenshot 2026-03-17 at 1.13.07 PM.png" alt=""><figcaption></figcaption></figure>
*   **Search**

    * Search by guest name, phone number, confirmation code, or booking status.

    <figure><img src="../.gitbook/assets/Screenshot 2026-03-17 at 1.13.53 PM.png" alt=""><figcaption></figcaption></figure>

## 3. Creating a booking from the dashboard

1. Tap **New booking** (or **Add booking**).

<figure><img src="../.gitbook/assets/image (1).png" alt=""><figcaption></figcaption></figure>

2. Enter:

* Date and time
* Party size
* Guest name and contact details
* Notes / special requests (optional)<br>

3. Confirm the booking.

The booking will appear in:

* The dashboard for that date
* The **Reservations** page (list/calendar)

## 4. Recommended daily routine

* **Before service**
  * Review today’s bookings and pending requests.
* **During service**
  * Use search to quickly pull up bookings and guest details.
* **After service**
  * Make sure any pending items are resolved (completed, cancelled, or no‑show).
